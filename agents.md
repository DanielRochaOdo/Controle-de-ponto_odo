# Regras para agentes

## Relato de mudanças

- Em cada mudança, informe se criou uma branch, uma migration ou uma function.
- Se criar um desses itens, informe o nome exato e o comando para executar, aplicar ou usar o item.
- Para uma branch, informe o comando para mudar para ela.
- Para uma migration, informe o comando para aplicá-la no ambiente correto.
- Para uma function, informe o comando para executá-la ou publicá-la.
- Se não criar um item, informe `Não criado` para esse tipo.
- Não invente comandos. Se o projeto não definir um comando, informe isso.

## Comunicação com o usuário

- Comunique-se no idioma usado pelo usuário, salvo pedido diferente.
- Aplique os princípios de clareza do ASD-STE100: use frases curtas, palavras simples, voz ativa e termos consistentes.
- Apresente uma ideia principal por frase.
- Dê instruções em etapas curtas e na ordem correta.
- Explique siglas e termos técnicos quando necessário.
- Ao escrever em inglês, siga o ASD-STE100 Simplified Technical English e use o vocabulário controlado quando aplicável.
